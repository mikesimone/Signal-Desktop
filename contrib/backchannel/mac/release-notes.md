Backchannel for Mac @VERSION@, built from Signal Desktop @SIGNAL_VERSION@.
Apple Silicon, macOS 14 or later. Signed and notarized.

Open the DMG and drag Backchannel to Applications. Then link it to your
phone like Signal Desktop: in Signal on your phone, Settings > Linked
devices > Link new device. Signal then asks whether to allow "Backchannel".
Allow it, and the page opens in Backchannel's own window.

Backchannel keeps its data apart from Signal Desktop, so both can run at
once.

This build stops working on @EXPIRES@, like every Signal Desktop build
90 days after it's made. Install a newer release before then.

Check the download against `SHA256SUMS` with `shasum -a 256 -c --ignore-missing SHA256SUMS`.

Backchannel is based on Signal Desktop. It is not made, endorsed or
supported by Signal Messenger.
